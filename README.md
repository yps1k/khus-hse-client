# Khus HSE Client

Неофициальный нативный **macOS**-клиент для HSE App X — расписание, оценки, поиск
по университету, свободные аудитории, ведомости и конспекты в одном приложении.
SwiftUI + Liquid Glass (macOS 26), с входом через OAuth2/PKCE аккаунтом ВШЭ.

> ⚠️ Неофициальный проект, не связан с НИУ ВШЭ. Использует приватный API
> приложения HSE App X (`api.hseapp.ru`), полученный реверс-инжинирингом.
> Только для личного использования.

## Возможности

| Раздел | Что делает |
|---|---|
| **Расписание** | Своё расписание по неделям; текущая пара подсвечена; имя преподавателя кликабельно → его профиль. |
| **Поиск** | Люди (студенты/преподаватели/сотрудники), группы, аудитории. Открытие профиля, копирование почты, расписание цели. История поисков. |
| **Свободные аудитории** | Выбор корпуса + Liquid-Glass слайдер интервала времени → список свободных аудиторий. |
| **Оценки** | «Итоговые оценки» (`/v2/grades`) и «Ведомости» — подключение Google Sheets, поиск своей строки по ФИО, пуш при обновлении. |
| **Дедлайны** | Активные дедлайны (`POST /v2/deadlines`). |
| **Уведомления** | Лента `/v2/notifications/feed`. |
| **Столовые** | Столовые и часы работы. |
| **Полезная информация** | Объявления из Telegram-канала «ПИ объявления». |
| **Конспекты лекций** | PDF-конспекты из канала «Маруся Конспектовна» со встроенным просмотром (PDFKit). |
| **Профиль** | Аватар-кружок вверху сайдбара; карточка профиля. |

## Авторизация

OAuth2 + PKCE против Keycloak ВШЭ (`saml.hse.ru`), публичный `client_id=app-x-android`.
Токены хранятся в Keychain, обновляются автоматически (единый refresh без гонок),
вход — через `ASWebAuthenticationSession`.

## Стек

- **SwiftUI**, цель **macOS 26** (Liquid Glass: `glassEffect`, `.glassProminent`)
- **PDFKit** — просмотр конспектов
- **AuthenticationServices** — OAuth-вход
- Проект генерируется **[XcodeGen](https://github.com/yonaskolb/XcodeGen)** из `project.yml`

## Сборка и запуск

```bash
brew install xcodegen          # если ещё не стоит
cd HSEClient
xcodegen generate              # генерирует HSEClient.xcodeproj
open HSEClient.xcodeproj        # Xcode → схема HSEClient, My Mac → ⌘R
```

Apple ID не требуется: подпись «Sign to Run Locally». При первом запуске один раз
разреши доступ к Keychain.
